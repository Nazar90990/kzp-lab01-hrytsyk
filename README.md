# Лабораторна робота №1: Кросплатформні засоби програмування
**Варіант 9:** Комунальні показники  

---

## 📌 Призначення програми
Програма призначена для автоматизованого зчитування, перевірки та аналізу показників комунальних послуг із файлу формату CSV. Вона виконує надійну обробку даних (хибні рядки пропускаються з виведенням інформативного повідомлення про помилку без аварійного завершення програми), обчислює сумарні та статистичні показники й генерує детальний звіт у консоль та файл.

---

## 📂 Формат вхідних даних
Вхідний файл має формат CSV (розділювач — крапка з комою `;`), що містить 4 поля для кожного запису:
`лічильник;споживання;дата;тариф`

**Приклад вмісту `data/input.csv`:**
```csv
Water;15.5;2026-09-01;25.40
Electricity;140.2;2026-09-02;4.32
Gas;45.0;2026-09-03;7.96
InvalidLineData;;2026-09-04;abc
