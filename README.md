# Консольний звіт (Варіант 9: Комунальні показники)

## Призначення
Програма читає записи з `data/input.csv`, перевіряє їх на валідність, обчислює комунальні показники (кількість коректних записів, сумарне споживання, загальну вартість та найбільше споживання) та формує звіт у консоль і файл `out/report.txt`.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою (`назва_лічильника; значення_споживання; дата; тариф`). Файл кодують у UTF-8. 

Приклад рядка:
`Електроенергія; 145.5; 2026-09-01; 4.32`
