# Звіт до лабораторної роботи № 1

## Тема і варіант

- Предметна область: Комунальні показники (Варіант 9)
- Номер варіанта: 9
- Операційна система: Windows 11

## Реалізація

Проєкт розроблено на мові Java 21 за допомогою середовища VS Code та системи збирання Maven. У головному класі `ua.lpnu.kzp.Main` реалізовано поблочне читування файлу `data/input.csv` з кодуванням UTF-8, валідацію полів за допомогою конструкцій `try-catch` (пропуск невалідних рядків із фіксацією помилок у звіті без аварійного завершення програми) та агрегацію чотирьох показників варіанта.

## Збірка і запуску

Для перевірки та пакування проєкту використовуються команди:
```bash
mvn clean verify
mvn package
java -jar target/lab01-1.0.0.jar
